# Business_App

Production-ready Flutter starter for a boutique accommodation app.

Next steps
- Install Flutter SDK and ensure `flutter` is on PATH.
- Run:

```bash
flutter pub get
flutter analyze
flutter run
```

Firebase

Secrets
